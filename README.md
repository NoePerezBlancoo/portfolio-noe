# Portfolio profesional - Noé Pérez Blanco

Portfolio profesional desarrollado con React, Vite, Tailwind CSS y Framer Motion para presentar mi perfil como Responsable IT / Tech Lead industrial especializado en desarrollo de software interno, digitalización industrial, integración IT/OT, automatización, ERP, trazabilidad, infraestructura y soporte a entornos productivos reales.

## Web online

https://portfolio-noe-zeta.vercel.app/

## Sobre el proyecto

Este portfolio está diseñado para mostrar mi experiencia real en entornos industriales, no solo como desarrollador web, sino como perfil híbrido entre software, sistemas, producción, infraestructura y coordinación técnica.

El objetivo principal es presentar de forma clara:

* Proyectos internos desarrollados para fábrica y departamentos.
* Sistemas de trazabilidad, ERP interno y automatización.
* Integración entre planta, maquinaria, PLC, OPC UA, bases de datos y sistemas corporativos.
* Responsabilidades como Responsable IT / Coordinador de Proyectos IT.
* Stack técnico aplicado a problemas reales de producción, mantenimiento, calidad, RRHH, dirección e infraestructura.

```

```
